# Proposal

## Why

当前工具只能对单张静态图片做霍夫圆检测：`src/circle_detector.py` 的 `detect_circles` 接收单帧 BGR 图像，`src/hough_circle_gui.py` 也只提供"导入图片"。实际使用时，检测参数往往要在连续画面上调（同一物体在不同帧的位置、遮挡与运动模糊都会影响 `param2` 与半径范围），逐帧手工导入图片既不现实，也无法复现。

本变更把"导入视频完成检测"整理成一份可接手的记录：说明要做什么、边界在哪、接口如何定、怎样验证。**本次只整理，不实现该功能。**

## What Changes

- 新增视频输入：选择本地视频文件，按固定帧间隔抽帧，对每帧复用现有 `detect_circles`。
- 新增逐帧结果记录：每帧记录帧号、时间戳、圆数量与各圆 `(x, y, r)`；没有检测到圆的帧同样保留一条空结果记录。
- 界面新增"导入视频"入口与播放/暂停、帧间隔控制；单图模式的行为与默认参数保持不变。
- README 补齐"样例获取方式"与"无头复现验收"，使接手人不必开图形界面就能复现现有验收结果。

## Capabilities

### New Capabilities

- `video-detection`：视频抽帧、逐帧检测、逐帧结果记录格式、无检测帧的处理与视频模式验收判定。

### Modified Capabilities

- `detection-gui`：新增视频导入入口与视频模式控制；单图模式行为保持不变（本变更只定义，不实现）。

## Impact

- 代码（计划）：`src/circle_detector.py` 增加视频抽帧与逐帧检测；`src/hough_circle_gui.py` 增加视频入口与播放控制；新增逐帧结果 CSV 写出。
- 文档（本次已完成）：README 增加"样例图片"与"无头复现验收"，并增加"交接状态"小节；本变更记录现状、未验证事项与后续待办。
- 依赖：不新增。视频解码使用现有 OpenCV 的 `VideoCapture`。
- 风险：不同编码/容器能否解码、WSLg 下视频播放性能、大分辨率视频的逐帧耗时，均未验证（见 `tasks.md`）。
