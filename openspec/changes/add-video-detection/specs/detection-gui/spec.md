# Spec Delta

## Purpose

在现有单图界面之外增加视频模式入口与逐帧播放控制。本增量只定义行为，不实现代码。

## ADDED Requirements

### Requirement: 视频模式入口
系统 SHALL 在主界面提供"导入视频"入口，与现有"导入图片"入口并列。选定可解码的视频后 MUST 进入视频模式，并在状态区显示当前帧号与时间戳。

#### Scenario: 导入视频
- **WHEN** 用户通过"导入视频"选择一个可解码的视频文件
- **THEN** 界面进入视频模式，显示当前帧画面以及帧号、时间戳

#### Scenario: 视频无法解码
- **WHEN** 用户选择的文件无法解码为视频
- **THEN** 系统显示错误提示，保持导入前的模式与画面，程序继续运行

### Requirement: 视频播放控制
视频模式下系统 SHALL 提供播放/暂停与帧间隔（`frame_step`）控制，并按当前参数逐帧检测；参数改动 MUST 触发重新检测，语义与单图模式的即时刷新一致。

#### Scenario: 播放与暂停
- **WHEN** 视频模式下用户点击播放后再点击暂停
- **THEN** 画面停止在当前帧，帧号与时间戳保持显示，不再推进

#### Scenario: 调整帧间隔
- **WHEN** 用户把帧间隔从 1 改为 5
- **THEN** 后续抽帧按每 5 帧一次执行，状态区显示的帧号相应跳变

### Requirement: 单图模式不受影响
进入并退出视频模式 MUST NOT 改变单图模式的现有行为：导入图片、参数调节与导出标注图的流程与结果保持不变。

#### Scenario: 回到单图模式
- **WHEN** 用户从视频模式切回单图模式并导入 `examples/coins.jpg`
- **THEN** 仍得到 2 个圆，预览与导出行为与切换前一致
