# Spec Delta

## Purpose

为图片提供可参数化的霍夫圆检测能力，返回圆心与半径，并能生成保留原图内容的圆圈标注图，供交互界面与无头验收共用。

## ADDED Requirements

### Requirement: 参数校验
系统 MUST 在接受检测前校验六个霍夫圆参数：`dp` 必须大于 0，`minDist` 必须大于 0，`param1` 与 `param2` 必须大于 0，最小半径必须大于等于 0，且最大半径必须大于最小半径（两者同为 0 表示不限制半径）。校验失败时系统 MUST NOT 执行检测，并 MUST 返回可读的错误说明。

#### Scenario: 最大半径不大于最小半径
- **WHEN** 用户提交最小半径 200、最大半径 150
- **THEN** 系统拒绝执行检测，并说明最大半径必须大于最小半径

#### Scenario: 参数合法
- **WHEN** 用户提交 `dp=1.2`、`minDist=300`、`param1=100`、`param2=100`、最小半径 0、最大半径 0
- **THEN** 系统接受参数并继续执行检测

### Requirement: 检测结果
系统 MUST 对输入图片执行霍夫圆检测，并返回零个或多个圆；每个圆 MUST 包含以图像左上角为原点的圆心像素坐标 `(x, y)` 与像素半径 `r`。返回的每个半径 MUST 位于给定的最小半径与最大半径范围内。相同图片与相同参数 MUST 产生相同结果。

#### Scenario: 检测到圆
- **WHEN** 对一张包含明显圆形边缘的图片使用有效参数执行检测
- **THEN** 返回的每个圆包含有效的圆心坐标与半径，且半径落在设定范围内

#### Scenario: 没有检测到圆
- **WHEN** 对一张图片使用有效但严格的高阈值参数执行检测
- **THEN** 系统返回空结果，不抛出异常

### Requirement: 标注图生成
系统 MUST 在原图的副本上为每个检测到的圆绘制可见的圆周与圆心标记，并 MUST NOT 修改原图。标注图 MUST 与输入图片具有相同的宽高。

#### Scenario: 绘制多个圆
- **WHEN** 检测返回两个圆
- **THEN** 标注图的对应位置出现两个圆周与两个圆心标记，且尺寸与原图一致

### Requirement: 硬币验收判定
使用 `examples/coins.jpg` 与验收参数执行检测时，系统 MUST 只返回两个圆，且两个圆分别贴合图中两枚大硬币的外缘。

#### Scenario: 检测 coins.jpg
- **WHEN** 对 `examples/coins.jpg` 使用两图共用的验收参数 `dp=1.2`、`minDist=300`、`param1=100`、`param2=100`、最小半径 0、最大半径 0
- **THEN** 检测结果恰好为两个圆，圆心分别约为 `(193, 193)` 与 `(567, 191)`，半径分别约为 180 与 179 像素

### Requirement: 盘沿验收判定
使用 `examples/cookie-plate.jpg` 与验收参数执行检测时，系统 MUST 只返回一个圆，且该圆贴合图中盘子的外沿。

#### Scenario: 检测 cookie-plate.jpg
- **WHEN** 对 `examples/cookie-plate.jpg` 使用两图共用的验收参数 `dp=1.2`、`minDist=300`、`param1=100`、`param2=100`、最小半径 0、最大半径 0
- **THEN** 检测结果恰好为一个圆，圆心约为 `(263, 259)`，半径约为 244 像素
