# Spec Delta

## Purpose

提供一个本地桌面图形界面，让使用者导入图片、调节霍夫圆参数并即时看到检测结果，最终导出带标注的图片。

## ADDED Requirements

### Requirement: 界面组成
启动程序后，系统 SHALL 显示单窗口界面，包含图片预览区、六个参数控件（`dp`、`minDist`、`param1`、`param2`、最小半径、最大半径）、导入按钮与导出按钮。每个参数控件 MUST 显示其当前数值，并允许在有限范围内调整。

#### Scenario: 启动界面
- **WHEN** 用户在具备图形环境的系统中启动程序
- **THEN** 窗口显示预览区、六个带当前值的参数控件、导入按钮与导出按钮

#### Scenario: 未导入图片时的导出
- **WHEN** 程序已启动但尚未导入任何图片
- **THEN** 导出操作不可用，且不会写出文件

### Requirement: 导入本地图片
系统 SHALL 通过文件选择对话框导入本地图片文件，支持 OpenCV 可解码的常见位图格式，包括 JPEG 与 PNG。导入成功后 MUST 在预览区按比例完整显示该图片，并立即使用当前参数执行一次检测。若文件无法解码，系统 MUST 显示错误提示、保留原有图片状态，且不崩溃。

#### Scenario: 导入有效图片
- **WHEN** 用户选择 `examples/coins.jpg`
- **THEN** 预览区显示该图片，状态区显示当前检测到的圆数量

#### Scenario: 导入无法解码的文件
- **WHEN** 用户选择一个内容不是有效图片的文件
- **THEN** 系统提示读取失败，预览区保持导入前的状态，程序继续运行

#### Scenario: 预览保持宽高比
- **WHEN** 导入一张宽高比与预览区不一致的图片
- **THEN** 图片按比例缩放并完整显示，不发生拉伸变形

### Requirement: 参数调节与实时预览
系统 SHALL 在已导入图片时，对任意参数的修改自动重新检测并刷新标注预览，不要求用户点击额外的“检测”按钮。预览 MUST 同时显示检测到的圆周与圆心。状态区 MUST 显示当前检测到的圆数量。参数不合法时，系统 MUST 显示错误提示并保持上一次有效预览。

#### Scenario: 调节参数立即刷新
- **WHEN** 用户在已导入图片后改变 `param2`
- **THEN** 预览在不需要额外确认操作的情况下更新，圆数量与标注同步变化

#### Scenario: 参数非法
- **WHEN** 用户把最小半径调到大于最大半径的值
- **THEN** 系统提示参数错误，并保留上一次有效的检测预览

#### Scenario: 没有检测结果
- **WHEN** 当前参数下没有检测到任何圆
- **THEN** 预览显示原图，状态区显示检测到 0 个圆

### Requirement: 导出标注图
系统 SHALL 允许用户将当前标注预览导出为图片文件，由保存对话框选择路径。导出文件 MUST 使用原图分辨率，包含当前参数下检测到的全部圆周与圆心标记，且不包含界面元素。导出成功后 MUST 提示保存路径；写入失败时 MUST 提示失败原因。

#### Scenario: 导出成功
- **WHEN** 用户导入图片、得到检测结果并选择可写路径导出
- **THEN** 系统在所选路径写出与原图同尺寸的标注图，并提示该路径

#### Scenario: 导出失败
- **WHEN** 用户选择一个不可写的目标路径
- **THEN** 系统提示写入失败，程序继续运行

### Requirement: 状态与错误提示
系统 SHALL 在状态区显示当前图片路径、检测到的圆数量以及最近一次操作结果。检测或文件操作失败时，系统 MUST 用可读文本说明原因，并 MUST NOT 使程序退出。

#### Scenario: 显示检测摘要
- **WHEN** 一次检测完成
- **THEN** 状态区显示当前图片路径与检测到的圆数量

#### Scenario: 读取失败不退出
- **WHEN** 图片读取失败
- **THEN** 系统显示错误说明，窗口保持可用
